# 📝 Flask To-Do List API with PostgreSQL

A simple RESTful API built with **Flask**, **SQLAlchemy**, and **PostgreSQL** for managing to-do tasks. It supports creating, reading, updating, and deleting tasks. Environment variables are managed securely using `python-dotenv`.

---

## 🚀 Features

- Add new to-do tasks
- View all tasks
- Update existing tasks
- Delete tasks
- JSON-based API
- Secure database credentials using `.env`

---

## 🛠️ Tech Stack

- **Backend**: Flask, SQLAlchemy
- **Database**: PostgreSQL
- **Environment Management**: python-dotenv
- **ORM**: Flask-SQLAlchemy
